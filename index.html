Mint Cinnamon Themes

Interactive, modular desktop theme & icon manager tailored for Linux Mint Cinnamon.

View Repository on GitHub

Installation Options

Option 1: Quick Online One-Liner (Recommended)

Run directly in your Terminal without cloning the repository beforehand:

curl -fsSL https://nottdevv.github.io/Mint-Cinnamon-Themes/install.sh | bash

Option 2: Manual Download & Clone

Clone the Git repository to review scripts locally before execution:

git clone https://github.com/NottDevv/Mint-Cinnamon-Themes.git cd Mint-Cinnamon-Themes chmod +x install.sh ./install.sh

Supported Themes

Windows 11

Fluent GTK themes (Light/Dark) with complete Windows icon packs.

macOS (WhiteSur)

Authentic Apple macOS UI layout and WhiteSur icon set.

ChromeOS

Clean Material Design desktop themes and Ozone icon pack.

Key Features

  • Modular Selection: Choose to install GTK themes, Icon packs, or both independently.
  • Variant Customization: Select Light, Dark, or Both theme variants during installation.
  • Backup & Restore: Safely backup your existing Cinnamon setup before applying modifications.
  • Clean Uninstall: Remove installed themes anytime without leaving orphaned files or affecting default themes.
  • Automatic Dependencies: Detects and installs required core utilities (`git`, `curl`, `bc`, `unzip`, etc.) automatically.

Mint Cinnamon Themes

Interactive & Modular Theme Manager for Linux Mint (Cinnamon)

Quick One-Line Install

Run this command in your Linux Mint terminal to launch the interactive theme manager:

curl -fsSL https://nottdevv.github.io/Mint-Cinnamon-Themes/install.sh | bash

Supported Themes

Windows 11

Light & Dark GTK themes + Fluent icon pack.

macOS (WhiteSur)

Authentic Apple UI elements and WhiteSur icons.

ChromeOS

Clean Material Design UI + Ozone icon set.

🇮🇷 راهنمای فارسی و نحوه استفاده

این پروژه یک ابزار تعاملی برای نصب، مدیریت و بازگردانی تم‌های محبوب روی محیط دسکتاپ Linux Mint Cinnamon است.

ویژگی‌های اصلی:

  • نصب مجزا یا هم‌زمان تم‌ها و پکیج آیکون‌ها
  • پشتیبانی کامل از هر دو حالت روشن (Light) و تاریک (Dark)
  • امکان تهیه پشتیبان (Backup) و بازگردانی (Restore) تنظیمات فعلی
  • حذف تم‌های نصب‌شده بدون آسیب به فایل‌های سیستم

# Mint Cinnamon Themes

Modern desktop themes for **Linux Mint Cinnamon** inspired by:

- 🪟 Windows 11
- 🍎 macOS
- 💻 ChromeOS

The project provides a simple interactive installer for installing and removing desktop themes and icon packs.

---

## ✨ Features

- Windows 11 inspired theme
- macOS / WhiteSur theme
- ChromeOS inspired theme
- Matching icon themes
- Interactive terminal interface
- Install themes individually
- Install all themes at once
- Uninstall themes individually
- Uninstall all managed themes
- Does not remove Linux Mint default themes
- Downloads theme projects from their upstream Git repositories
- Designed for Linux Mint Cinnamon
